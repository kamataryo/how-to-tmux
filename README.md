# How to tmux

ブラウザで動く tmux の講座で、ブラウザ内の Linux VM（[v86](https://github.com/copy/v86)）で本物の tmux 3.5a を動かし、[xterm.js](https://github.com/xtermjs/xterm.js) で表示します。サーバー側の処理はなく、静的ファイルの配信だけで動きます。
